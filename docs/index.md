# Rugby7 Referee Fatigue Analyzer

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21443419.svg)](https://doi.org/10.5281/zenodo.21443419)

Scientific software for analysing fatigue and match demands in Rugby Sevens referees.

## Main features

- Subjective fatigue analysis.
- Match-demand analysis.
- Research mode with private local data.
- Demonstration mode with anonymized data.
- Automated scientific reports.
- Heatmaps and spatial visualizations.
