# Installation

## Requirements

- Python 3.10 or later
- Git
- PowerShell

## Clone the repository

    git clone https://github.com/SportsLabResearch/Rugby7-Referee-Fatigue-Analyzer.git
    cd Rugby7-Referee-Fatigue-Analyzer

## Install dependencies

    python -m pip install mkdocs mkdocs-material

## Run the application

    python main.py
